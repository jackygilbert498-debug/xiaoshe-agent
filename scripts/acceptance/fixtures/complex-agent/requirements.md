# 插件目录归一化需求

实现 `normalizePlugins(entries)`，用于整理插件清单：

- `entries` 必须是数组；否则抛出 `TypeError`。
- 每项必须是对象且具有非空字符串 `id`；`id` 去除首尾空白并转为小写，非法项抛出 `TypeError`。
- 相同规范化 `id` 的插件合并，保留首次出现的位置与首次出现的非空 `name`。
- `capabilities` 只接受字符串数组；每项去除空白、丢弃空字符串，并按首次出现顺序去重。重复插件的能力追加合并。
- 返回全新的插件对象和能力数组，不得修改输入数组或输入对象。

只修改 `src/plugin-catalog.mjs`。测试、需求和参考资料都属于验收输入，不得改写。
