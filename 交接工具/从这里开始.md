## 工程结构

- `XS/`：产品 Host、安装/启动入口和当前原生壳实施工作树。
- `XS/packages/native-shell-legacy-adapted/`：当前正式 root consumer；`ui-baseline/` 是老版不可变副本，`ui/` 是删改后的工作视觉层。
- `XS/packages/native-shell/`：保留的原 Product Client Consumer。
- `XS/packages/native-shell-candidate/`：保留的 V5 历史候选。
- `XS/packages/native-shell-candidate-bundle/`：保留的 V5 覆盖层。
- `XS/packages/native-shell-candidate-v6/`：保留的 V6 历史候选。
- `XS/packages/native-shell-candidate-v6-bundle/`：保留的 V6 历史覆盖层。
- `XS/packages/product-bundle/`：Provider/Consumer Product Bundle。
- `XS/packages/memory/`：Phase 4 Profile 所属记忆 Provider/Client。
- `XS/packages/heartbeat/`：Phase 5 DSH Jobs 后台检查和恢复状态。
- `XS/packages/plugin-governance/`：Phase 6 审计、一次性确认、健康与回滚治理。
- `XS/packages/runtime-contract/`：实现无关的最小 Session 生命周期契约及测试 Provider。
- `XS/packages/runtime-dsh-provider/`：DSH Client Runtime 的公开面适配器。
- `XS/packages/legacy-dsh-skin/`：只供兼容 Profile 显式加载的旧 UI。
- `XS/交接工具/离线工件/xiaoshe-product/`：Phase 7 的可搬移 Product 闭包、哈希清单与独立安装器。
- `XS/runtime/DSH/`：唯一 Agent Harness 内核及完整 Git 历史。
- `XS/runtime/xiaoshe-legacy/`：屏幕/AX/UIA 迁移能力与必须保留的脏工作树。
- `XS/交接工具/`：入口、状态、完整性清单、安装与验证工具。

## 不携带的内容

- `.env`、API Key、Token、个人凭据；
- DSH 个人会话、`.state`、UI token、PID/lock、日志；
- `node_modules`、`dist`、`lib`、缓存和临时 Profile；
- 旧小蛇内部含旧凭据风险的重复 `Harness交接/`。

这些排除项不会阻止继续开发；新设备需要重新安装依赖、配置模型凭据和授予操作系统权限。
