# 小蛇：临时对话、项目迁移与能力设置实施方案

## 目标

1. “新对话”不再依赖当前项目：未指定项目时，在小蛇管理的临时对话根目录中为每个会话创建独立目录。
2. “新项目”成为新对话旁的独立次级操作；项目内仍可直接创建会话。
3. 临时对话可移入项目。迁移必须保留历史，同时把后续工作目录和权限边界切换到目标项目。
4. 审核模式改用更符合小蛇的任务语义，但保持现有沙箱和审批策略不变。
5. 修复左上品牌文字裁切，并把设置首页重组为小蛇真实能力入口。

## 设计

- 临时会话：`session.create({ loose: true })`，Host 在配置的 `looseSessionsRoot/<session-id>` 下创建目录。
- 移入项目：将完整已完成历史 fork 到目标项目工作目录，绑定目标项目后归档原临时会话；空白会话直接在目标项目新建并归档原会话。
- 项目创建：侧栏主按钮继续创建临时对话，旁边新增较小的项目按钮，复用已有目录选择和 workspace.create 流程。
- 审核文案：只读 / 逐项确认 / 自主执行；仅改产品表达，不放宽底层策略。
- 设置：首页增加“小蛇能力中心”，集中真实存在的响应风格、桌面桥接、视觉与动作能力。

## 验证

- Host schema/API 单测覆盖临时目录与目标项目 fork。
- Client runtime 单测覆盖无项目新建与移入项目。
- Sidebar/workspace 组件测试覆盖双按钮和迁移动作。
- 品牌主题测试覆盖不裁切样式。
- 运行受影响包测试、类型检查和 Windows 构建；随后在 3080 页面做可见交互检查。
