# 小蛇原生壳界面候选 V4 自适应实施记录

**状态：** 本机工程、隔离 Profile 与实时 HTTP 验证通过；用户视觉复核待确认；未推广、未替换原壳

**日期：** 2026-08-25

**范围：** 只修正 `@xiaoshe/native-shell-candidate` 在宽屏和超宽屏上的比例、对齐与空态垂直节奏；保留 V3 的三栏信息架构、视觉语言、真实服务接线和隔离候选边界

## 问题判断

用户提供的截图视口为 `2269 × 1214`。V3 在这个尺寸仍使用 `236px | 1fr | 292px` 固定侧栏和 `800px` 主内容上限，导致中栏约 `1741px`，但有效内容只占约 46%；标题、空态、输入器和两侧栏看起来彼此疏离。屏幕尺寸只是暴露条件，根因是候选缺少宽屏模式，而不是显示器本身异常。

## V4 设计决策

- 用 CSS 自定义属性统一管理左栏、右栏、内容宽度、阅读宽度和中栏边距，不为单一截图写死位置。
- 标准屏保留 V3 的紧凑三栏；`1600px` 起让侧栏和内容区连续增长；`2200px` 起进入稳定的超宽屏档。
- 标题、任务流和输入器共享同一内容网格，避免三个区域分别居中产生视觉漂移。
- 空任务流改用剩余空间网格居中，不再依赖 `vh` 或固定上边距；有任务时仍保持正常从上到下的阅读流。
- 保留 `1180px / 860px / 620px` 的窄屏降级、左右栏收放、深浅主题、键盘焦点和 reduced-motion 契约。
- 品牌标识继续只逐字节复用 `runtime/xiaoshe-legacy/ui/assets/snake.svg`，没有生成、重画或用文字 `S` 代替。

## 响应式合同

| 视口 | 左栏 | 中栏 | 右栏 | 内容上限 | 中栏单侧留白 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `1440px` 标准屏 | 236 | 912 | 292 | 800 | 56 |
| `1920px` 宽屏 | 264 | 1328 | 328 | 1040 | 144 |
| `2269px` 用户截图 | 264 | 1677 | 328 | 1080 | 298.5 |

补充降级：`≤1180px` 使用 `204px / 276px` 侧栏；`≤860px` 左栏收敛为 52px、右栏变为抽屉；`≤620px` 输入器与操作区进入紧凑排列。
