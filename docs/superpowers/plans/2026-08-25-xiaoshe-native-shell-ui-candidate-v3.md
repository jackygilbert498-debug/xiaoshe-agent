**状态：** 本机工程、隔离 Profile 与实时 HTTP 验证通过；用户视觉复核待确认；未推广、未替换原壳

**日期：** 2026-08-25

**范围：** 只精修 `@xiaoshe/native-shell-candidate` 的视觉细节，保持 `会话 | 任务过程 | 工作台` 三栏、真实服务接线和候选隔离边界不变

## 修正原因

V2 的结构方向已经获得用户认可，但微观视觉语言仍带有演示稿感：小于 11px 的文字过多、圆角尺寸任意、多处渐变与重阴影叠加、右栏重复 `LIVE` 标签、会话选中态和输入器都偏厚重。V3 不重做信息架构，而是建立一套受自动测试约束的克制细节系统。

## V3 设计决策

- 字号下限固定为 11px；宋体只承担产品名与标题，界面说明使用系统中文字体，等宽字体只保留给必要的技术事实。
- 圆角只允许 `4px / 8px / 12px` 三档或正圆；不再出现任意胶囊、混合圆角和气泡尾巴。
- 全界面只保留一处极轻的标题渐变；正式品牌标识使用单色遮罩，不再给标识叠加自制渐变。
- 会话选中态改为细玉绿色竖线与轻底色，移除发光点和卡片边框。
- 右栏删除重复 `LIVE`，通过字号、留白、细分隔线和状态色表达层级。
- 输入器取消默认重阴影，聚焦时才出现低强度外环；操作按钮回到统一 8px 圆角。
- 空态提示由三个笨重胶囊收敛为带细分隔线的短语；保留正式蛇形标识的低透明度水印。
- 深浅主题、左右收放、三档响应式、键盘焦点和 reduced-motion 契约保持不变。
- 标识仍只逐字节复用 `runtime/xiaoshe-legacy/ui/assets/snake.svg`，禁止生成式或文字 `S` 替代。
