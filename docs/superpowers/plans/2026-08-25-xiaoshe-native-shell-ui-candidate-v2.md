# 小蛇原生壳界面候选 V2 实施记录

**状态：** 本机工程与隔离 Profile 验证通过；用户视觉判断待确认；未推广、未替换原壳

**日期：** 2026-08-25

**范围：** 只迭代 `@xiaoshe/native-shell-candidate`，继续复用 DSH 执行内核和现有 Product 服务

## 修正原因

V1 虽然满足架构隔离和真实服务接入，但视觉语言过度发明，使用“巢册 / 证据脊线 / 脉册”等陌生术语，浅色三列的空间比例和组件密度也偏离用户熟悉的小蛇界面。V2 不再另造信息架构，以旧版小蛇的黑色三栏工作台为基线，保留 DSH 模块边界，只重做候选 Client 的视觉、文案和交互层次。

## V2 设计决策

- 桌面默认深色，三栏语义固定为 `会话 | 任务过程 | 工作台`；右栏内部使用 `状态 | 记忆 | 系统` 标签页。
- 展开列宽为 `236px | minmax(0, 1fr) | 292px`，收起后左右栏分别为 `52px` 与 `48px`；窄屏按契约逐级压缩。
- 左栏只承担项目、搜索、会话与连接状态；中栏只承担任务流、审批和输入；右栏只投影真实凭证、上下文、心跳、记忆与插件事务。
- 默认空态采用安静舞台，不再展示笨重胶囊或伪指标。任务建议改为轻量行内入口；消息按用户、助手、行动、审批、验证的语义区分，而不是统一卡片。
- 保留深浅主题、键盘焦点、语义区域、`prefers-reduced-motion` 和响应式断点。
- 标识只能逐字节复用 `runtime/xiaoshe-legacy/ui/assets/snake.svg`；禁止手绘、文本 `S` 或生成式替代。
- 候选仍通过公开 Client 服务读取真实状态，不复制执行内核，不绕过审批，不伪造已完成能力。

## 额外基线修复

根验证暴露 Homebrew Node 23 的 npm CLI 位于 `libexec/lib/node_modules/npm/bin/npm-cli.js`，原插件治理审计只搜索 `lib/node_modules`，导致真实 fixture 审计返回 500。修复仅扩展 npm 入口候选路径，并增加确定性单测；插件治理事务、审批和沙箱语义未改。
