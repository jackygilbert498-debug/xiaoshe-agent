# 小蛇原生产品壳统一修正设计：控件、设置与可编辑记忆

**日期：** 2026-08-27
**状态：** 用户已整体授权直接实施，无需逐项再次确认
**实施目标：** `@xiaoshe/native-shell-legacy-adapted` 现行产品壳
**视觉母版：** 旧版小蛇既有比例、字体、颜色、留白与组件语言

## 1. 背景与结论

当前壳已接回 Phase 4–8 的多项公开能力，但仍存在四类明确问题：

1. 权限和思考强度使用浏览器原生下拉框，展开方向、语义和细节均不符合产品壳质量；
2. 左下角同时出现右栏页签导航和命令面板提示，造成重复入口与信息层级混乱；
3. V6 迁移时把记忆页误收窄为只读摘要，丢失已经存在的创建、修订、遗忘与恢复界面；
4. 空态蛇形水印的线条偏重，破坏旧版轻盈感。

这轮修正不是重做视觉系统。除被点名的交互和缺失功能外，旧版的布局尺度、字体、颜色、透明度、渐变、圆角、留白和左上角 Logo 均保持不变。

## 2. 不可变视觉边界

- 保留当前三栏比例、侧栏密度、主舞台留白、输入器尺寸和右栏宽度。
- 保留既有亮色/暗色 token 与玉色品牌语言，不引入通用后台模板风格。
- 空态蛇形水印只把形态学轮廓的有效厚度从约 `1.5px` 调为约 `0.8px`；尺寸、位置、透明度和渐变不变。
- 左上角品牌 Logo 不受本次水印调整影响。
- 权限与思考强度共用同一套轻量弹层几何、阴影、发丝线和动效，但使用各自正确的图标、文案和风险语义。
- 所有新增交互保持键盘可达、焦点可见，并遵守 `prefers-reduced-motion`。

## 3. 权限上弹菜单

权限控件改为自绘按钮与向上展开的选择弹层，不再使用透明覆盖的原生 `select`。

- 弹层固定向输入器上方展开，宽度约 `248px`，避免跌出窗口底部。
- 行内显示权限名称和一行真实说明；当前项使用浅玉灰底和勾选标识。
- `只读`、`工作区写入`、`完全访问` 继续映射现有 `permissionPresets` 公共服务。
- 只有 `完全访问` 使用克制的危险色，并保留既有二次确认；确认前不能调用服务。
- 点击外部、按 `Escape` 或完成选择后关闭弹层。
- 使用 `aria-haspopup`、`aria-expanded` 和可识别的单选菜单语义。

## 4. 思考强度上弹菜单

闪电表达速度或加速，不适合表示模型推理档位，因此替换为细线脑回路图标，并移除醒目的黄色。

- 弹层同样向上展开，显示 `关闭`、`低`、`高`、`最大`。
- `关闭` 的实现语义是“不额外指定思考强度，交由模型默认行为”，不伪造服务端不存在的硬关闭能力。
- 低/高/最大继续写入现有模型目录服务公开的 effort 值。
- 每项显示简短效果说明；当前项采用玉灰选中态。
- 不使用浏览器原生下拉框；外部点击、`Escape` 和选择后关闭。

## 5. 左下角与设置中心

左下角恢复为旧版熟悉的齿轮 `设置` 入口：

- 删除常驻的 `任务 / 记忆 / 系统`，右栏页签仍是查看实时状态的唯一入口；
- 删除常驻的 `Ctrl K 命令面板` 文案，保留快捷键本身；
- `Ctrl K` 只在设置的快捷键说明中出现；
- 设置使用独立的大浮层/工作页，不塞入 292px 右侧检查栏；
- 右栏继续承担会话级实时状态、记忆和运行能力信息，不承担全局配置。

### 5.1 一切皆插件边界

设置中心只负责窗口、分组、导航、可访问性和保存反馈。设置项由拥有该能力的插件通过公开贡献合同提供：

- 外观/语言贡献通用设置；
- 助手与模型插件贡献助手、模型和服务商设置；
- 权限插件贡献默认权限与安全检查；
- 插件治理贡献插件与能力设置；
- 原生壳贡献快捷键说明与高级诊断入口。

贡献合同至少包含稳定 `id`、标题、排序、可用性、只读说明或可执行操作。未安装、未连接或底层尚未公开写接口的插件不出现可编辑开关。壳不得保存一份与 Provider 相互竞争的影子配置。

### 5.2 第一版只展示真实能力

第一版允许出现的内容：

- 通用：现有主题切换；只有语言/发送方式服务实际可写时才显示对应控件；
- 助手：只有默认助手或回答风格服务可写时才显示；
- 模型与服务商：展示当前可用模型和服务状态，配置动作必须由模型插件提供；
- 权限与安全：展示当前权限预设及其真实边界，默认值必须由权限插件写入；
- 插件与能力：调用现有受控插件治理流程；
- 快捷键：展示已经实际绑定的 `Ctrl K`、发送、换行和斜杠命令；
- 高级与关于：版本、运行目录、诊断与日志等真实信息或真实入口。

`记忆与数据`、通知、自动更新等底层尚未提供的设置不做无效开关。只读状态必须明确标注，不伪装成可保存配置。

## 6. 恢复可编辑记忆

只读记忆摘要是迁移回归。Memory 插件已经公开并实现创建、修订、遗忘、恢复和 revision 冲突检查，因此右栏记忆页恢复编辑能力，同时继续以 Memory Provider 为唯一事实源。

- 范围：全局记忆与当前项目记忆；项目不可用时禁用项目写入并说明原因。
- 列表：显示记忆文本、范围、状态、修订号和更新时间；活动项与已遗忘项可切换查看。
- 新建：调用 `memoryLifecycle.remember`，不直接请求私有路径。
- 编辑：对原条目做带 revision 的修订，由 Provider 生成新版本；不原地篡改历史。
- 遗忘/恢复：调用 `memoryLifecycle.setState` 并携带当前 revision。
- 冲突：收到 revision 冲突后刷新快照、保留用户草稿并给出可重试提示。
- 失败：显示可恢复错误，不吞掉异常，不先做乐观伪成功。

右栏宽度保持不变，因此编辑器采用紧凑表单与单列卡片，不扩大侧栏，也不把记忆编辑迁移到主对话区。

## 7. 状态与数据流

- 会话、时间线、模型、权限、记忆和插件治理继续来自各自 Product Client 公共服务。
- 壳只保存短暂 UI 状态：哪个菜单打开、设置窗口是否打开、记忆草稿与正在编辑的条目。
- 服务快照变化后由既有订阅触发重渲染；壳不复制长期业务状态。
- 插件确认令牌继续只存在于组件状态中，不渲染、不写日志。

## 8. 自适应与交互验收

- 宽屏保持既有三栏；弹层不改变输入器和侧栏宽度。
- 右栏转 overlay 的断点下，记忆编辑仍可滚动、提交和关闭。
- 手机宽度下，设置窗口变为全屏工作页，导航和内容改为纵向，主要操作不溢出。
- 选择弹层应自动保持在可视区域内，但视觉方向始终从触发器向上。
- 验收至少覆盖 1920×1080、1440×900、1024×768、760×900、390×844，并检查横向溢出、遮罩关闭、键盘关闭与焦点可见性。

## 9. 完成定义

只有以下条件全部满足才可称为完成：

1. 新增行为测试先失败、实现后通过；
2. 原有适配壳与 Memory 插件测试、类型检查、构建均通过；
3. 真实浏览器挂载成功，控制台无新增错误；
4. 权限与思考强度均为向上自绘弹层，危险确认仍有效；
5. 记忆创建、编辑、遗忘、恢复至少完成一次真实服务往返验证；
6. 设置入口取代左下角重复导航，且只展示真实可用内容；
7. 多尺寸截图/DOM 验收无明显溢出和遮挡；
8. 形成命令、结果、已知边界和下一设备启动方式的交接记录。

## 10. 后续增量：标题栏比例与左右视觉重量

用户后续确认现有信息内容正确，但指出标题区占比过高，并且左侧会话栏因粗体、主按钮和选中底色显得明显重于右侧检查栏。本增量仍属于旧版视觉边界内的手术式修正，不改变三栏宽度、品牌字体、颜色体系或中央空态。

- 桌面标题栏由双行封面式结构收回为单轴信息栏：标题、运行事实和主题按钮共享视觉中心线；标题字号、字重与颜色保持不变。
- 标准桌面标题栏目标高度为 `92px`，横向留白继续与消息流和输入器对齐；`≤760px` 时允许状态换行，`≤520px` 继续隐藏次要运行事实。
- 左右栏宽度及其拖动边界保持原合同：标准桌面 `232px / 292px`，不通过扩大右栏解决视觉失衡。
- 右栏事实卡从透明虚线占位改为实体发丝线卡面，使用浅卡面、深标题、次级说明和 `2px` 状态线形成层级；不增加无意义装饰。
- 默认卡只使用中性玉灰；`healthy` 等真实健康状态投影为 `ok`，`lost / delayed / backoff` 投影为 `warn`，`idle / running / paused` 保持中性。颜色不得脱离 Provider 事实自行推断。
- 右栏页签选中态和分区标题增加克制的粗细对比与浅色块，但中央舞台继续拥有最高视觉优先级。

## 11. 后续增量：长会话中的“我的消息”导航

长会话需要快速回看用户自己发出的某一轮，但不引入第二份会话状态，也不照搬连续波浪或装饰性缩略图。导航仍以 Product `taskTimeline` 的公开快照为唯一事实源：

- 只为 `kind === "user"` 的时间线事件生成标记；标记保留原事件序号，点击时定位对应事件节点，不按文本搜索。
- 标记默认是克制的短发丝线；鼠标悬停或键盘聚焦时向右延长、使用玉灰高亮，并浮出“第 N 条 + 该轮内容”的小预览卡。
- 预览折叠连续空白并限制为 96 个字符；无文字的图片轮次显示“无文字内容”，不会因空文本丢失导航点。
- 导航只是时间线的派生视图，不持久化、不写回 Provider、不复制 Session Log，也不改变原消息内容。
- 对话滚动容器距底部超过 `max(160px, 30% 可视高度)` 时，输入器上方淡入一个细线向下按钮；回到底部后立即退出 DOM，不常驻占位。
- 点击标记与回底均尊重 `prefers-reduced-motion`；键盘焦点、ARIA 名称和消息预览在无鼠标场景下同样可用。
- 手机和平板继续保留全部标记；标记贴近对话区左缘，预览宽度受视口约束，不改变旧版三栏尺寸、输入器宽度或侧栏断点。
