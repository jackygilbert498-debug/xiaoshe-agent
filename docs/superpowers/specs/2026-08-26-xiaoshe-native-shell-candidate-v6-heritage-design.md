# 小蛇原生产品壳候选 V6：旧版视觉继承设计

**日期：** 2026-08-26
**状态：** 用户已授权自主实施；独立候选，不替换旧版、V5 或正式 Product Profile
**视觉母版：** `runtime/xiaoshe-legacy/ui`
**功能接线基线：** `@xiaoshe/native-shell-candidate`（V5）与 Phase 4–8 的公开 Client 服务

## 1. 问题与目标

V5 已经接入会话、时间线、审批、完成凭证、心跳、记忆和插件治理，但它重新设计了字体、密度、控件尺度与默认主题，造成旧版小蛇的轻盈留白、精细比例和既有识别度丢失。V6 不再重新发明视觉系统，而是把用户已调整满意的旧版界面作为视觉母版，只为新能力增加必要的信息和操作。

目标是同时满足：

1. 旧版视觉身份可辨认且尺寸稳定；
2. Phase 4–8 能力通过真实公开服务呈现，不做静态假面板；
3. “一切皆插件”边界不退化；
4. 宽屏、普通桌面、窄屏和手机宽度均可用；
5. V6 独立安装、独立验收、可卸载，绝不覆盖旧版或 V5。

## 2. 不可变视觉合同

以下内容直接继承旧版，不做审美重构：

- 默认主题是亮色“云白薄荷”，暗色保留旧版 `ink-jade` 墨玉主题。
- 基础字体使用 `Inter / Noto Sans SC / PingFang SC / Microsoft YaHei`；技术信息使用 `JetBrains Mono / Cascadia Code / Consolas`；不把会话标题改为大面积宋体。
- 桌面三栏为 `232px | minmax(0, 1fr) | 292px`；左右折叠宽度均为 `48px`。
- 应用底部状态栏固定占用 `26px`。
- 品牌区、侧栏按钮、搜索框、会话树、主标题、输入器、右侧页签、面板标题、折叠按钮沿用旧版视觉尺度。
- 输入器最大宽度 `720px`、圆角 `20px`；发送按钮恢复旧版 36px 圆形 CTA，不使用 V5 的 104×42 文字大按钮。
- 新会话继续是侧栏唯一实心药丸 CTA；项目按钮保持 ghost。
- 颜色、发丝线、圆角、阴影、动效时长和 9 秒品牌流光沿用旧版 token。
- 内容优先，右栏是轻量 inspector，不演变成第四列、卡片仪表盘或持续抢眼的重型台账。

## 3. 页面结构

### 3.1 左栏：旧会话/项目外壳

- 品牌标与 `小蛇 / HARNESS · ATELIER` 原位保留。
- `会话` 标题右侧保留 `＋ 新会话` 和 `＋ 项目` 两个旧式控件。
- 搜索框、项目/会话两级视觉、当前会话玉色边线、底部命令提示和折叠按钮保留。
- 当前服务只公开会话目录而没有完整项目写接口时，项目按钮保持可见但以明确的“不支持”反馈结束，不伪造持久化。

### 3.2 中栏：旧对话舞台

- 标题、工作区 meta、连接/运行状态、主题切换和折叠面板入口沿用旧版布局。
- 时间线是 DSH Session Log 的投影，不建立第二份消息真源。
- 任务输入、审批、运行/停止和发送继续调用公开 Product Client 服务。
- 空态恢复旧版“小蛇”字标、正式蛇形水印、低频流光和克制文案。
- 审批卡和错误态沿用旧版组件语言；不把系统状态永久堆在消息流内。

### 3.3 右栏：状态 / 记忆 / 系统

右栏仍是旧版三页签 inspector，宽度 292px。

- **状态：** 当前任务、完成凭证、上下文、心跳/后台、待审批。
- **记忆：** 全局/项目记忆数量和生命周期事实；只展示 Memory 插件返回的公开快照。
- **系统：** 能力中心摘要、Host 插件清单、受控插件变更入口。

插件安装/更新/卸载继续遵守现有治理流：候选审计 → 事实披露 → 十分钟一次性确认 → 事务结果。确认令牌仅保存在组件状态中，不渲染、不写日志。Host 插件“无 OS 沙箱”的现实边界必须显示。

## 4. 自适应合同

- `>1080px`：三栏常驻，精确保持 232/292；宽屏只增加中栏留白，不放大左右栏和控件。
- `<=1080px`：主网格为 `210px | 1fr`，右栏改为从右侧打开的 overlay；不能在关闭时覆盖内容或截获指针。
- `<=760px`：主网格只保留中栏，左栏和右栏都改为独立 overlay，并提供可键盘访问的关闭入口。
- `<=520px`：标题、消息流与输入器缩小边距；输入工具条换行；状态栏隐藏次要统计；触控目标不小于 32px。
- 折叠按钮和 overlay 按钮语义一致，`aria-expanded` 与实际状态同步。
- `prefers-reduced-motion: reduce` 下关闭动画与平滑滚动。

验收视口至少覆盖 2269×1214、1920×1080、1440×900、1024×768、760×900、390×844；同时检查横向溢出、overlay 可关闭、输入器可见、主要区域不重叠。

## 5. 插件与数据边界

V6 是新的 Client 插件 `@xiaoshe/native-shell-candidate-v6`，由独立覆盖 Bundle `@xiaoshe/native-shell-candidate-v6-bundle` 安装。覆盖 Bundle 只停用正式 `xiaoshe-native-shell` seat 并插入 V6，不修改 V5、不修改 Product Bundle 内其他行。

V6 只能消费以下公开服务：

- `agentRuntimeSession`
- `sessionCatalog`
- `taskTimeline`
- `contextGovernance`
- `userApproval`
- `memoryLifecycle`
- `pluginGovernance`
- `slots`

心跳继续通过 Product 公开 HTTP 端点读取。V6 不读取 `runtime/DSH` 私有源码或状态目录，不创建 Loader、Workspace 管理器、事件日志或执行内核，不直接执行插件安装命令。

## 6. 工程隔离与来源策略

- 旧版 UI 是视觉参考源，但 V6 构建产物自包含；运行时不依赖旧版开发服务器。
- V5 的服务接线逻辑可以复制后在 V6 内独立维护，V6 不 import V5 包。
- 正式蛇标从 V6 自己的 `assets/snake.svg` 端点提供，字节与旧版正式资源一致。
- 旧版关键 token 和布局规则以 V6 自己的 CSS 文件冻结，并由行为/浏览器验收验证；不在构建时偷偷改写旧版文件。
- 当前工作树包含尚未提交的 Phase 4–8 依赖，因此不从旧 HEAD 创建缺少依赖的 Git worktree；隔离单位是新增包、独立 Profile、独立 DSH_HOME 和独立端口。

## 7. 验证与完成定义

V6 只有在以下证据全部形成后才算本机完成：

1. 先失败后通过的单元/集成测试覆盖视觉合同、服务调用、插件确认、生命周期与 overlay 状态；
2. V6 与 V6 Bundle 的 test/typecheck/build 通过；
3. 新鲜隔离 Profile 离线打包、安装、启动、HTTP 探针、卸载边界通过；
4. 真实浏览器挂载后检查 DOM、computed style、控制台错误和六档视口截图；
5. 根质量门、Python、所有 XS workspace 包门禁和三工作树 `git diff --check` 通过；
6. 更新交接文档、证据清单和清单哈希，生成新的完整交接包并做解包校验。

本机无法真实完成的 macOS/Linux/额外 DPI 与多显示器验收必须标记为 `release-held`，不能用本机模拟或旧证据冒充。本设计也不授权提交、合并、替换正式壳或发布。
