# 决定 0001：DSH 内核与小蛇能力插件

## 决定

小蛇以 DSH Profile 作为唯一用户运行面。DSH 拥有 Agent 循环、模型、会话、工具流水线、审批和沙箱；ModLens拥有静态图像语义理解；小蛇 Bundle 拥有主动桌面观察、视口坐标、GUI 动作和动作验证。

迁移期通过标准输入输出 JSON-RPC 调用旧 Python 模块。协议只暴露屏幕能力，不暴露旧小蛇的模型循环、会话、权限或工具注册表，因此不会形成双内核。

## 放弃的方案

继续把旧小蛇整体重构成另一套 DSH 会长期维护重复的会话、审批、沙箱和工具系统。把所有旧模块一次性翻译成 TypeScript 会同时改变实现语言、运行时和产品架构，无法隔离回归。让用户分别启动 DSH 与旧小蛇会拆分上下文、记忆和权限状态。

## 验证义务

Bundle 必须能从 Profile 单独卸载；桥接进程必须随插件卸载达到静止；动作必须经过 DSH 审批并在执行层校验视口；模型可见的工具调用与结果必须由 DSH 会话日志记录；任何外部真机缺口必须明确标注。
