# Loop + Graph 界面跟进与最新源码交接

## 判断与范围

新能力需要局部界面跟进，不需要重新设计三栏结构、配色或标识。检查发现：当前需要处理的事项会被长任务图挤到后面；旧任务图和当前任务区分不足；异常反馈藏在详情中；验收依据中的内部编号不容易对应具体条件。

本次修改沿用现有桌面组件与终端格式：

- 待回答、待审批、排队消息及运行异常优先展示。
- 过期任务图默认折叠为历史记录，保留原目标和节点记录，不代替本轮任务。
- 长任务图收起非重点节点，保留展开入口；当前进展、阻塞和中断仍可见。
- 图的最近反馈与当前阻塞原因可直接阅读，完整详情仍可展开；反馈是执行记录，不是额外安全禁令。
- 验收依据显示对应的验收条件文本，不只显示内部 ID；仍称“验收评估”，不声称独立验证。
- 终端 `:tasks` 补充图级最近反馈，与桌面读同一份状态。

改动不增加第二套调度器，不改权限，不改 Graph 核心状态，不把等待记录显示成成功。没有图的老会话继续使用原有任务视图。主题、标识及字号设置保持原样。
