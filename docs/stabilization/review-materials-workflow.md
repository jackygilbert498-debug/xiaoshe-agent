# 高频工作流：审核资料整理与可核验交付

适用范围：本地审核说明、素材清单和已获授权的网页表单／文档。初期优先明确、重复的资料处理，不承诺任意网站自动操作。

## 使用前

- 指定输入目录、参考标准、输出目录和目标网页；输出必须是新文件，不覆盖原始资料。
- 明确哪些字段可提交。图片、个人信息或内部资料不能因为“本地执行”就默认可以上传给模型或网站。
- 真实网站首次登录时由使用者接管，登录完成后交回；不要把密码和验证码写进对话。
- 网页对外发送／发布前，先展示待提交内容并取得对应授权。

## 可复制的任务说明

> 读取我指定目录中的资料，按我提供的审核标准整理清单。保留原文件，不猜测缺失信息；冲突和缺项单独列出。先把结果写入指定的新输出文件并回读核对条数和关键字段。向我展示准备提交到目标页面的内容，等我确认后再提交。提交后同时核对页面回读和可获取的保存结果，不把按钮点击或“已提交”提示当作唯一完成证据。失败时说明卡在哪一步，不重复发送。

## 六个可检查的环节

1. 输入取证：记录实际读取了哪些文件、条数及关键标识；缺文件及时停止对应分支。
2. 整理：保持来源标识，缺项为空并解释，不让模型自行补造。
3. 本地输出：限定目标目录、确认写入，回读结构、条数和关键字段；原资料摘要不变。
4. 提交前核对：展示目标页面、待提交内容和预期影响；授权只覆盖本次对象。
5. 网页操作：使用专用浏览器；超时或断线后先查保存状态，不能盲目重复提交。
6. 交付回执：列出本地输出、网页结果、独立核验、失败项和未验证项。

## 验收边界

本阶段的自动夹具使用临时本地资料和本机测试网站，不读取真实账号，不付费调用模型。它证明读写、浏览器操作与保存回读能串联，不证明模型已通过该任务。真实模型及真实网站的重复任务结果必须单独登记，才能用于评估实际完成率。
