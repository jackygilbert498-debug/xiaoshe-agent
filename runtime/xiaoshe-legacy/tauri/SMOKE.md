# 小蛇桌面壳 · 冒烟清单（tauri/）

装好工具链（BUILD.md §1）后逐项验证。每步标注期望；任何一项不符 = 冒烟失败。

## 0. 前置

```bash
python3 scripts/export_icons.py   # 图标最新（5×2 张 PNG，读回校验全 OK）
cd tauri && cargo tauri build     # 或 cargo tauri dev 走开发态
```

## 1. 冷启动 ≤1.5s 到可交互

- 秒表计时：双击启动 → 窗口出现「正在启动」→ 跳到带 token 的小蛇界面并可输入。
- 期望：从进程起到**界面可交互** ≤1.5s（python 侧车初始化与壳启动并行外的主要耗时；
  超时先查 READY_TIMEOUT 是否被顶满，再看 stderr 服务日志）。
- 地址栏不可见，但界面 URL 形如 `http://127.0.0.1:7788/?token=…`（可用 devtools 确认）。

## 2. 错误面（PLAN G4：如实报错不白屏）

- 2a. **杀掉 python 进程**：任务管理器/`kill` 掉 `python run.py serve` →
  期望窗口切到错误页，文案「小蛇服务进程已退出」，朱砂错误块，不白屏。
- 2b. **无 python 环境**：临时把 PATH 清空（或 XIAOSHE_PYTHON 指向假路径）启动 →
  期望错误页写明「未找到可用的 Python ≥3.11」。
- 2c. **端口被占**：先手动 `python3 run.py serve --no-browser` 占住 7788，再起壳 →
  期望错误页「未输出就绪行」，dev 终端能看到端口冲突真实报错。

## 3. 托盘与关停顺序

- 3a. 点窗口 ✕ → 窗口消失但**服务不死**：托盘图标仍在，`curl http://127.0.0.1:7788/`
  仍有响应（401/页面均可，证明活着）。
- 3b. 托盘菜单「显示小蛇」→ 窗口原样恢复（会话不丢）。
- 3c. 托盘菜单「退出（停止服务）」→ **进程树干净**：
  `ps aux | grep run.py`（Win：任务管理器查 python）应无残留；壳进程亦退出；
  端口 7788 释放（再起不冲突）。

## 4. 单实例

- 壳运行中再次双击启动 → **不弹第二个窗口**，既有窗口被唤起聚焦。
- 期望系统只有一个壳进程、一个 python 侧车。
