# 视觉盲区与想象补强 · 可能性地图

> 性质：**头脑风暴产物 / 可能性地图,不是施工清单**(2026-07-12)。目的是把视觉思路的边界画出来、
> 专挑边界之外的东西,供后面拍板取用。**先不做任何一条。**
> 三部分:①现有方案的隐含假设(边界)②七个盲区 + 17 条有论文/项目支撑的补强(经并行研究工作流核实)③三个想象跳跃(组合已有能力的质变)。

## 0. 关键框架:现有视觉方案的四个隐含假设
上一轮统一方案(《视觉能力升级统一方案》)+两份蓝图,几乎全建立在四个没说破的假设上:
> **静态的、按需的、单感官的、单帧的——对屏幕做感知。**
每打破一个,就露出一片没被覆盖的盲区。下面七个盲区就是这四个假设的不同侧面。

评级标注:**【白捡】**=纯本地技术、不额外花 Kimi 钱、不加依赖 ｜ **【花 Kimi 钱】**=推理即用无新依赖但多调几次 Kimi ｜ **【要新依赖/算力】**=需引进本地模型/库。

---

## 一、时间盲区(最核心)：只会拍"死照片",看不见两步之间发生了什么
每步动作后拍一张静止截图就决策。可现实里两次拍照之间屏幕会自演化:弹窗中途插入、列表刷新、一闪而过的 toast、加载转圈——全会漏判/误判。
- **GUIWatcher `wait_until_settled`** 【白捡】← **本轮最该先做**:隔几十毫秒连拍两张算像素差,连续两帧稳定或超时才动手。把原生 UI 里"盲等 sleep / 点未渲染好的位"换成"看稳了再点"。粗版 PIL 像素差即可(论文那个要标注的 YOLO 砍掉)。**直接修已知痛点**(骨架屏灰块被误判成出错、点到没渲染好的位)。(arXiv 2502.04202)
- **DynamicUI 多帧感知** 【花钱】:容易出事的动作后(提交/登录/切页)按小间隔连拍几张→去冗余→只把相关帧喂 Kimi(本就吃视频)。做成"疑似动态才触发",非每步默认。补"跨帧"这一维。(2604.25380,training-free)
- **LivingScreen 参数化 watch(时长,帧率)** 【花钱】:把"观察"升格成带预算的动作——"看多久=花多少钱",由 Kimi 出参数+"别看太多也别太少"软约束。(2606.04701,只出 benchmark、借设计模式)

## 二、主动感知盲区：Kimi 看不清时不会自己"凑近再看一眼"
- **FOVEA 可解性探测** 【花钱】:看不清时围绕初判裁 3-4 个候选框,各问一句"从这块你能回答吗?(是/否)",挑"是"概率最高的放大看。妙在**绕开置信度数值**(闭源 Kimi 拿不到 logits,正好不需要)。**建议缝进已在计划的 RegionFocus**,非独立造;探测调用设硬上限护配额。(2605.01345,ICML 2026)
- ⚠️ **诚实空白**:这一维**没有便宜的落地版**——要么花钱、要么先不做。

## 三、感官融合盲区：结构(a11y)和像素两只眼睛从不互相校验(可靠性收益最实)
- **感知融合鸿沟·点前一致性闸门** 【花钱】:a11y 树会**说谎**(控件改名/懒加载/复用致标签陈旧),实测 agent 有 30-79% 概率盲信假标签点错。点击前对"文字标签关键"的目标,把 UIA 报的 bbox 裁下让 Kimi 确认"这块像素上的字是不是 UIA 说的那个",不一致就降级。和"点后汇报变化"串成**点前检+点后验双闸**。
- **TOCTOU 派发前守门(PUSV)** 【白捡】← **强烈推荐**:高危动作(click/press_keys/type_text)派发前 0.1 秒**重跑 list_windows**看焦点窗还是不是意图那个/有没有新弹窗盖住。**复用现成 list_windows 几乎零成本**,系统性解掉小蛇踩过的两个坑(focus_window 误报成功、observe 幻影元素)。键盘动作打错焦点窗是真实高危。真收益不只防攻击,更防"良性动态变化"(异步渲染/通知/焦点漂移)。

## 四、感知成本盲区：每看一眼都烧钱,却没"该不该看"的前置判断(省钱纪律,搭车做)
- **OSWorld-Human 冗余观测准则** 【白捡】:"打字→回车"这类通常不改界面的动作不触发新 observe(最强 agent 也多走 1.4-2.7 倍冗余步)。
- ⚠️ **诚实空白**:**"看之前先判值不值"的可靠机制小蛇拿不到**——ToolGate/To Call 的真方法要么需训练小控制器、要么读模型隐状态,小蛇都没有;且 To Call 论文自证"让模型口头自评要不要看"不可靠。只剩纯规则去重(价值有限)+提醒式清单(非硬机制)。别当省钱确定收益宣传。预算维已被现有"软预算"覆盖。

## 五、隐私盲区：observe 一截,把整屏(含后台窗口/他人隐私)无差别送云
现有隐私护栏只"匹配已知敏感模式"(扫密钥)。真正暴露是**整帧无差别外发 Kimi 云**——完全正交的第三条轴。
- **CAPED 便宜版** 【白捡】← **推荐**:截图**裁到活动窗口** + UIA 的 **IsPassword 属性把密码框整块涂黑**,零成本。小蛇起点比 CAPED 还高(它要花算力解析像素成元素,小蛇 UIA 免费就有带坐标元素树)。相关性遮蔽流水线作二期,保留"疑似相关就留"防掐断任务。
- **WebPII 零依赖路** 【白捡】:用现有 **ocr 词框** 套其 PII 分类法(尤其订单号/追踪号/金额这类"交易级可再识别标识"),上云前画遮蔽矩形。高保真路要 OpenVINO 依赖(默认不引)。
- **AgentDAM 隐私感知 CoT** 【白捡】:系统提示加"送屏/OCR/表单/外送前先自问这步真需要哪些字段"。几乎免费。(Meta 开源基准,只借方法论;"性能不掉"已更正为有小幅权衡)

## 六、记忆盲区：每次都"第一次见"这个软件(多为前瞻储备)
- **ActionEngine 应用状态机地图** 【白捡存储/建图用 Kimi】← 本组最有分量:把"这软件页面怎么跳转"存成持久 JSON 图,**边用边学**,下次同软件查图给规划提示。observe 的 UIA 树是不靠像素建图的理想底料。待解:桌面窗口没稳定 URL,需自设"页面身份指纹"。
- **AppAgentX 宏压缩** 【白捡】:反复走的动作链(开计算器→点数字→点等号)沉淀成命名"宏"存本地 JSON、关键词检索(无记忆 16.9%→链式 70.8%)。**部分覆盖**(小蛇 episodic+Reflexion 已覆盖一部分),增量精修。坚持标准库、别引 Neo4j/向量库。
- **AGMem 反例** 【白捡·设计纪律】:将来加视觉记忆时,"塞整屏历史"会**反噬点击精度**(实测 grounding 误差 +8.6)→只裁"动作相关区"别塞整屏。**前瞻避坑,非当前缺口**(小蛇现在压根没视觉记忆),紧迫性低。

## 七、空间精确盲区：能算准的(对齐/对比度/相对位置)却在"目测"
- **DesignChecker 确定性设计检查** 【白捡】:对齐共线、WCAG 对比度(4.5:1)、间距一致性、字号——纯 Python 算术 linting(RGB→亮度公式算对比度、边缘坐标投影查对齐),又准又免费,替 render_check 现在"截图→VLM 目测"。原生应用走 UIA 真实 bbox。(UIST'24)
- **VISER 叠水平线** 【白捡·待验证】:送图前叠 3 条等距水平线诱导空间扫描。⚠️增益是 GPT-4o 实测、迁 Kimi 未验,论文自警"视觉修改可能遮挡反伤",且 GUI 场景本该用 observe bbox 直接算——**限定作用域(无 a11y 的照片/图表/游戏画布)+必须真机 A/B 才敢开**。更接近"待验证猜想"。

## 八、三个想象跳跃(组合已有能力的质变,不需新模型,难在编排)
1. **自己吃自己的狗粮**:小蛇写完 web app → 用自己的视觉+浏览器操作,像真人一样点进去走流程、发现 bug 再改。把**创作+感知+操作**焊成"自动化端到端测试"——给用户做的任何软件都能自己视觉验收。
2. **看一遍就学会**:用户手动做一次(录屏/连续截图)→ 小蛇看懂流程、抽象成步骤、下次自己复现(programming-by-demonstration)。把"教小蛇"从写提示词降维成"做给它看一遍"。接盲区一(时间)+六(记忆)。
3. **视觉世界模型**:动手前先"想象"点了这个按钮屏幕会变成什么(forward model),动作后用真实截图对预测——预测错得离谱=其实没看懂界面,该停。比 TVAE"事后核验"更早逮出误解。

## 推进排序(拍板用):先补这 3 个盲区(高价值+低门槛+对着已知痛点,都有零依赖便宜起步版)
1. **时间盲区 → GUIWatcher `wait_until_settled`**:最纯白捡、直接修骨架屏/加载态误判。时间维是本轮靶心,从最便宜一条切入。
2. **时序盲区 → TOCTOU list_windows 派发前守门**:复用现成 list_windows 几乎零成本,系统解掉 focus_window 误报+observe 幻影两个已知坑。可靠性收益最实。
3. **隐私盲区 → CAPED 便宜版(IsPassword 涂黑+裁到活动窗口)**:零成本高价值,契合现有安全纪律,堵"整屏含后台/他人隐私外发云"真实暴露面。配 AgentDAM 隐私 CoT 几乎免费再加一道。
> 共性:都有零依赖便宜起步版、都对着已知痛点/真实暴露、都打破一个隐含假设(单帧/观察不过期/整帧外发)。感知成本组(省钱纪律)搭车做;空间精确+记忆作储备。

## 九、诚实空白(找了但没干净落地方案的地方)
1. 主动感知(该看哪一眼)**没有便宜落地版**——FOVEA 方向对但要花钱,更像缝进 RegionFocus 的机制。
2. "花钱看前先判值不值"的可靠机制**小蛇拿不到**(需训练/隐状态);口头自评被论文自证不可靠。只剩纯规则去重+提醒清单。
3. 高召回本地视觉 PII 模型**要么接新依赖(OpenVINO)、要么降级**(ocr 词框+规则,召回打折)——依赖取舍待拍板。
4. 跨会话视觉记忆是**避坑参考,非当前缺口**(小蛇现在没视觉记忆),紧迫性低。
5. VISER 对 Kimi 的净增益**未证实**,更接近待验证猜想。
