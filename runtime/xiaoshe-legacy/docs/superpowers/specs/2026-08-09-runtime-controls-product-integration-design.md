## 1. 目标

本轮一次性收敛六项需求：

1. 在界面提供脚本沙箱、工具联网、在线心跳控制；
2. 关闭沙箱后脚本改为宿主机直接执行，而不是被禁用；
3. 例行系统消息默认折叠，警告和错误继续显眼展示；
4. 已完成编程任务中的合格脚本可由用户保存为待审工具；
5. Windows 任意终端输入 `S` 可唤醒小蛇终端版；
6. 形成可执行的手机 PWA 与飞书机器人接入方案，并保留 Kimi、配置 DeepSeek。

## 2. 运行控制语义

### 2.1 三个互不冒充的开关

- **脚本隔离**：开时，自生成脚本和已批准的自定义工具进入 AppContainer/Seatbelt；沙箱不可用时明确失败。关时，脚本仍可运行，但改为宿主机直接执行，并明确标注“未隔离”。
- **工具联网**：`off | proxy | open`，独立于脚本隔离。它控制宿主工具、后台命令和新启动子进程的出网环境。沙箱自身仍保持断网；若用户需要脚本直接访问外网，应使用“直接模式”。
- **在线心跳**：控制界面到本地服务的 15 秒在线探测和最后响应时间展示。它不控制 TaskWorker 的租约续期，也不关闭 WebSocket 的传输保活。

提供一键 **直接模式**：`sandbox_enabled=false` 且 `network_mode=open`。界面使用琥珀/红色风险状态，显示“宿主执行 · 外网开放”。关闭直接模式不猜测用户偏好，用户分别调整两个开关。

### 2.2 状态与生命周期

用户选择原子写入 `.state/runtime-controls.json`，版本为 `1`，默认：

```json
{"version":1,"sandbox_enabled":true,"network_mode":"off","heartbeat_enabled":true}
```

- 交互会话：更新后对下一次工具调用立即生效；已经运行的后台进程不被偷偷重启。
- Task v2：Run 启动时把当前控制值冻结进 `policy_json`，运行中不受随后全局切换影响。
- 所有执行仍通过既有权限、审批、效果账本、超时和预算机制；关闭沙箱不是自动授权。
- TaskWorker 租约心跳始终启用，用户通过停止/取消任务结束运行。

### 2.3 API 与界面

- `GET /api/runtime-controls`：返回持久选择和真实有效状态；不返回密钥或环境变量。
- `PATCH /api/runtime-controls`：只接受三个已知字段的部分更新，未知字段和非法枚举拒绝。
- `GET /api/runtime-controls/heartbeat`：返回服务端 UTC 时间和当前开关状态，不写聊天消息。
- 右栏“系统”增加“运行控制”卡片：两个独立安全控制、心跳脉冲、最后响应、直接模式按钮、沙箱后端实况和风险说明。

## 3. 会话降噪

普通 `message.append` 中 `role=system` 的消息始终汇总到唯一、默认收起的“系统记录 N 条”。不删除原消息，也保留搜索内容。`system.alert` 中 `warn` / `error` 继续留在消息流；`info` 继续只作轻提示。不得靠中文文案猜测严重程度。

## 4. 保存为工具

首版只接受以下候选：

- Task 状态为 `Succeeded`；
- 当前 ChangeSet 未 stale，工作区版本仍一致；
- 候选来自 ChangeSet 的 `untracked` 文本 artifact；
- 文件后缀为 `.ps1`，artifact 校验通过，重建后的字节 SHA-256 与 manifest 一致。

按钮只在上述条件成立时出现。用户选择脚本并填写工具名、说明和参数后，后端调用既有 `user_tools.propose()`，仅写入 `pending/`。它不会自动批准、激活或热加载；仍需人工审查，批准后从下一会话生效。首版不把增量 patch、当前工作区实时文件、敏感文件、二进制或其他语言伪装成 PowerShell 工具。

## 5. Windows 终端命令

安装器在当前用户 PATH 已包含的 `%LOCALAPPDATA%\Microsoft\WindowsApps` 写入 `S.cmd`，不依赖 PowerShell profile，不修改执行策略。无参数执行 `py -3 <repo>\run.py`，所有参数原样转发。安装幂等，仓库移动后重跑即可更新路径。

## 6. 外部接入交付物

- 手机：响应式 PWA + Tailscale Serve 私有 HTTPS，精确 Origin，一次性二维码配对，可撤销设备会话；离线只缓存静态资源和脱敏只读快照。
- 飞书：企业自建应用 + 应用机器人 + SDK 长连接；首版不需要公网入站。消息、卡片、Task v2、幂等、3 秒回调和凭据边界写成实施清单。
- DeepSeek：凭据只进入 Windows DPAPI 保护的 `.state/model_secrets.bin` 或被 Git 忽略的本机环境；Kimi 不删除、不覆盖，额度错误由真实调用返回。

- 不重置、清理或覆盖现有脏工作树；现有改动属于交接基线。
- 只暂存本任务的新增文件和精确补丁块；不得整文件带入无关继承改动。
- `.env`、`.state`、日志、密钥文件及任何凭据不暂存、不回显。
- 每个任务必须有 RED、GREEN、独立审查和独立提交；每批完成后做集中验收。
- 所有安全状态必须如实展示；不可把 AppContainer/Seatbelt 标成“未隔离”，也不可把宿主执行标成“沙箱”。
