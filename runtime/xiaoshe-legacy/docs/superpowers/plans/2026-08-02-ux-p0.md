# 体验优化 P0（15 项）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改契约 v1、安全语义、品牌几何和 token 持久化的前提下，完成专项报告确认的 15 项 P0：统一模态与键盘闭环、四态错误恢复、真实回执、第一体验、窄窗可达、视觉/文案一致和可复用验收机制。

**Architecture:** 以 `ui/js/modal.js` 作为唯一模态生命周期管理器；以现有 store/REST/WS 作为真实状态源，不增加事件或路由；以 `Promise.allSettled` 和显式状态枚举补齐错误态；以 CSS token 作为尺寸/水印的单一事实源。自动化在开发侧使用 Playwright + 系统 Chrome，运行时仍是零构建、零新增依赖的原生 ES Modules。

**Tech Stack:** Vanilla HTML/CSS/ES Modules、Python 3.10+ 标准库、unittest、Playwright（仅开发走查）、现有 `scripts/serve_demo.py`。

## Global Constraints

- [ ] **Step 1: 实现唯一公共接口**

`ui/js/modal.js` 导出五个入口：`openModal(options)` 返回 `{element, close(reason)}`；
`closeTop(reason = "programmatic")` 关闭栈顶；`isModalOpen()` 返回 `stack.length > 0`；
`confirmModal(options)` 返回 `Promise<boolean>`；`promptModal(options)` 返回 `Promise<string|null>`。

`openModal` 的 `options` 形状固定为：

```javascript
{
  content,                         // HTMLElement，必填
  trigger = document.activeElement,
  initialFocus = null,             // HTMLElement 或 CSS selector
  role = "dialog",                // dialog | alertdialog
  label = null,
  closeOnBackdrop = true,
  onClose = null,
}
```

核心行为按以下代码结构实现，不另造第二套 Esc/Tab：

```javascript
const stack = [];
const FOCUSABLE = [
  "button:not([disabled])", "[href]", "input:not([disabled])",
  "select:not([disabled])", "textarea:not([disabled])", "[tabindex]:not([tabindex='-1'])",
].join(",");

function top() { return stack.at(-1) || null; }

function focusables(entry) {
  return [...entry.layer.querySelectorAll(FOCUSABLE)]
    .filter((node) => !node.hidden && node.getClientRects().length > 0);
}

function onKeydown(ev) {
  const entry = top();
  if (!entry) return;
  if (ev.key === "Escape") {
    ev.preventDefault();
    ev.stopPropagation();
    entry.close("escape");
    return;
  }
  if (ev.key !== "Tab") return;
  const nodes = focusables(entry);
  if (!nodes.length) { ev.preventDefault(); entry.content.focus(); return; }
  const first = nodes[0], last = nodes.at(-1);
  if (ev.shiftKey && document.activeElement === first) { ev.preventDefault(); last.focus(); }
  else if (!ev.shiftKey && document.activeElement === last) { ev.preventDefault(); first.focus(); }
}
```

`openModal` 必须：

1. 取 `#modal-root` 与 `.app`，为 content 设 role/`aria-modal=true`/label；content 没 tabindex 时设 `tabindex=-1`。
2. 创建 `.modal-layer`，把 content append 进去；背景点击只在 `ev.target === layer` 时关闭。
3. 若已有下层，把下层 `inert=true`；首层打开时 `.app.inert=true`。
4. 把 `{layer,content,trigger,onClose,close}` push；只在首层安装 document capture `keydown`。
5. `queueMicrotask` 聚焦 initialFocus/首个可聚焦/content。
6. close 只允许幂等执行一次；移除本层；恢复下层 inert 或清 `.app.inert`；最后一层移除 keydown；调用 onClose(reason)；焦点归还仍在文档且可见的 trigger，否则聚焦下层 content。

`.modal-layer` 接管遮罩：

```css
#modal-root { position: fixed; inset: 0; z-index: var(--z-modal); pointer-events: none; }
.modal-layer {
  position: absolute; inset: 0; pointer-events: auto;
  display: flex; align-items: flex-start; justify-content: center; padding-top: 14vh;
  background: color-mix(in srgb, var(--ink) 24%, transparent);
}
.modal-layer[inert] { visibility: hidden; }
```

```javascript
async function pushMemory() {
  const api = window.XS.panels?.memory;
  if (!api?.update || !store.get().connected) return;
  api.startLoading?.();
  const [layers, skills] = await Promise.allSettled([
    net.get("/api/memory/layers"), net.get("/api/skills/pending"),
  ]);
  api.update({
    layers: layers.status === "fulfilled" ? layers.value : null,
    skills: skills.status === "fulfilled" ? skills.value : null,
    errors: {
      layers: layers.status === "rejected" ? String(layers.reason?.message || layers.reason) : null,
      skills: skills.status === "rejected" ? String(skills.reason?.message || skills.reason) : null,
    },
    retry: pushMemory,
  });
}
```

- [ ] **Step 3: 实现客户端一次性回执等待器**

`ui/js/command-receipt.js`：

```javascript
import * as net from "./net.js";
import * as store from "./store.js";

export function sendCommandWithReceipt(name, args = {}, { match, timeoutMs = 2000 } = {}) {
  return new Promise((resolve, reject) => {
    let settled = false;
    const finish = (fn, value) => {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      offMessage();
      offAlert();
      fn(value);
    };
    const offMessage = store.on("message.append", (msg) => {
      if (msg?.role !== "system") return;
      if (match && !match(msg)) return;
      finish(resolve, msg);
    });
    const offAlert = store.on("system.alert", (alert) =>
      finish(reject, new Error(alert?.text || `${name} 执行失败`)));
    const timer = setTimeout(() => finish(reject, new Error(`${name} 回执超时`)), timeoutMs);
    if (!net.command(name, args)) finish(reject, new Error("未连接，命令未发送"));
  });
}
```

注意：listener 必须在发送前注册；resolve/reject/timeout 都必须统一卸载，禁止监听器泄漏。
