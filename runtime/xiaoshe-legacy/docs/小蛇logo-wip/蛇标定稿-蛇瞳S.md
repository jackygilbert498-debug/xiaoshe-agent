## 用法规则

- **≥24px 品牌位**（侧栏/启动页/大图）：渐变版。
- **功能位/小尺寸**（favicon、16px）：单色版（渐变在小尺寸发浑，实测结论）。
- 空态水印：渐变描边、低透明度（暗 .14 / 亮 .10）。

## 资产位置

- 源 SVG：`ui/assets/snake.svg`（单色 currentColor，注释含渐变版改法）
- 内联 sprite：`ui/assets/icons.svg` + `ui/index.html` 的 `#snake` symbol（存档/外部引用用；页面内品牌位不走 <use>——Chrome/Edge 对 <use> 克隆内容里的 mask url() 不解析，方瞳会丢，品牌位已改纯内联，2026-08-01 实测复现）
