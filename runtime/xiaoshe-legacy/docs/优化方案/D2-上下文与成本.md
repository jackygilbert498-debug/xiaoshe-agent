### 2a · 真 token 计量（readiness 4/5，小，先做）

**目标**：压缩的触发与预算从"按字符估算"改为"以 provider 真实 token 为准、本地估算兜底"。把 Kimi 返回的 `usage.prompt_tokens` 作为"上一轮真实上下文规模"锚点喂回压缩决策；provider 没给 usage（首轮/流式缺失/离线测）时用轻量本地估算器兜底。不引第三方依赖、跨 Win/Mac、保 190 绿测。

**三层设计（全锚真代码）**：

1. **计量层——新增 `harness/tokens.py`**（纯标准库 re/json，纯函数便于 TDD）：
   ```python
   import re, json
   _CJK = re.compile(r'[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef]')
   def estimate_text(s):
       if not s: return 0
       cjk = len(_CJK.findall(s)); rest = len(s) - cjk
       return cjk + (max(1, round(rest/4)) if rest else 0)  # CJK≈1tok/字, ASCII≈4字/tok；兜底估算，真值以 provider usage 为准
   def estimate_messages(history):
       return sum(estimate_text(json.dumps(m, ensure_ascii=False)) for m in history)
   def from_usage(usage):
       if isinstance(usage, dict):
           v = usage.get('prompt_tokens')
           if isinstance(v, int) and v >= 0: return v
       return None
   ```
   `estimate_messages` 用 `json.dumps(m, ensure_ascii=False)` 与 `compaction._msg_len`（`compaction.py:24`）同源序列化，非文本内容不抛。

2. **决策层——`compaction.maybe_compact` 加 token 语义**（改 `compaction.py:90-93`）：
   ```python
   from . import tokens, config
   DEFAULT_BUDGET_TOKENS = config.get_int('KIMI_CONTEXT_BUDGET_TOKENS', 128000)
   def maybe_compact(history, model_fn, budget_chars=DEFAULT_BUDGET_CHARS,
                     keep_recent=DEFAULT_KEEP_RECENT, summarizer=None,
                     used_tokens=None, budget_tokens=DEFAULT_BUDGET_TOKENS):
       tok = used_tokens if used_tokens is not None else tokens.estimate_messages(history)
       # OR 触发（务必是 or，不是 and）：token 超预算为主判据，字符预算是防大 base64 骗过估算器的安全网
       if not (tok > budget_tokens or total_chars(history) > budget_chars):
           return False
       # …cut/summarize 逻辑（compaction.py:95-111）一字不动…
   ```
   模块 docstring 更新为"触发：真 token 超预算（provider usage 优先，本地估算兜底），字符预算作安全网"。`DEFAULT_BUDGET_CHARS=24000` 保留。

**吸收对抗评审的修正（4 条据实收口）**：
- **`_last_usage` 语义据实注释**：它是"上一轮**发出时**的输入规模"，用作下一轮阈值是**有意的滞后锚点**——比真实略低（少算最新一轮用户输入那部分），压缩偏晚一档，**不是"最准/最可信锚点"**。方案原文的"最准"措辞删掉，改成"滞后锚点，无正确性硬伤"。注释写清避免误导后续维护者。
- **`_last_usage` 不入回滚快照**：它是运行时缓存（只影响下轮压缩阈值、不影响 history 一致性），不进 `agent.py:172-177` 的 `BaseException` 回滚。某轮失败回滚 history 后 `_last_usage` 仍是上次成功值，偏保守（略早压），无正确性风险——docstring 点明。
- **相邻缺陷 #1 显式声明**：本方案正好改 `agent.py:133` 这行（`maybe_compact` 在 try/回滚块之外先就地改写 history），**本轮不碰该缺陷、留独立一刀**（别装作没看见）；若要顺手修，则 `pre=list(history)` 连同 todos 一起纳回滚。默认声明"留独立一刀"。
- **CJK 正则边界**：`[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef]` 只覆盖 CJK 统一+符号+全角，漏 Ext-A/假名/谚文——注释明说"仅中文优先兜底、真值以 provider usage 为准"，别被当通用 tokenizer 误用。纯 ASCII 极短串（1-3字）经 `max(1, round(rest/4))` 兜成 1，把这条边界钉进契约测试。
