## 要你拍板的取舍（各文档详述）
- 是否允许**可选**引入 Docker/bubblewrap（D1 沙箱、D3 eval）——默认 local 不引依赖、行为不变，容器是显式 opt-in。
- 是否**可选**引入本地 tokenizer（D2 token 计量）——默认用 provider usage + 字符兜底，tokenizer 是可选精度升级。
- prompt caching 的收益取决于 Kimi 后端是否支持缓存（D2 已标注收益边界）。
