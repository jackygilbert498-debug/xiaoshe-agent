# 01 · 心智模型:我们到底在造什么

> 读这一章不需要任何代码基础。读完你心里要有一张图:**agent 是什么、它怎么转、我们要往上加哪些零件。**

---

## 一、一个寓言:车手与车

有个天才赛车手,闭着眼都能过弯。可你把他丢进沙漠——没车、没方向盘、没油门——他再会开,也只能干站着。

有人想"造个会开车的机器人",于是焊了一万行 `if-else`:遇左弯打方向、遇红灯刹车……车是动了,可一遇没写过的路况就撞墙。他造的不是车手,是个**提线木偶**。

聪明的工程师不去"造车手"——**车手(大模型)早就够聪明了**。他去**造一辆好车**:方向盘、油门、仪表盘、刹车、安全带。然后请车手上车,自己退到一边。

> **车手 = 大模型(Kimi / Claude / DeepSeek……),它的"会开车"是训练出来的,你买不到也造不出。**
> **车 = Harness(载具),方向盘油门仪表盘刹车,全是工程造出来的。我们要造的,就是这辆车。**

这就是那句心法:**Agency(感知、推理、行动的能力)来自模型,不是代码编排出来的。你造的不是智能,是"智能栖居的世界"。**

## 二、所有 agent 的共同心跳:那个循环

不管后面加多少花样,最核心的永远是这个圈,转个不停,直到模型说"做完了":

```
   你提个目标
       │
       ▼
 ┌──────────────┐
 │  问 模型      │  ← 把"对话历史 + 能用的工具"丢给模型
 │ "下一步干啥?"│
 └──────┬───────┘
        │
   模型说"我要用某个工具"        模型说"我说完了"
        │                            │
        ▼                            ▼
 ┌──────────────┐                  结束 ✅
 │ 代码去执行工具 │
 │ (跑命令/读文件)│
 └──────┬───────┘
        │
        ▼
 把结果塞回对话历史,回到"问模型"  ← 圈就这么转
```

**全部秘密就在这:聪明的是模型,代码只负责打杂——把工具结果递回去。** 你不用懂这段代码怎么写;你只要懂**这个圈在转**,以及"对话历史"就是 agent 的记忆。

后面所有的"机制",都只是往这个圈上**挂零件**——圈本身几乎不变。

## 三、一辆完整的"车"由什么构成

把任何 agent 剥到底,harness 就这几大件:

| 零件 | 大白话 | 对应车上的什么 |
|---|---|---|
| **工具 Tools** | 给它一双手:读写文件、跑命令、上网、调你的总台 | 方向盘 + 油门(让它能动手) |
| **观测 Observation** | 给它眼睛:报错日志、命令输出、文件内容 | 仪表盘(让它看到发生了什么) |
| **权限 Permissions** | 给它边界:危险操作要先问你 | 刹车 + 安全带 |
| **知识 Knowledge** | 给它专长:文档、规范,用到时再给(不一股脑塞) | 随车手册 |
| **记忆 Memory** | 让它记住跨次对话的事 | 行车记录仪 |

我们要造的 harness,就是把这几大件,围着那个循环一件件装上去。

## 四、20 个机制 · 一张地图(概念级,看个全貌就行)

这是我们会一块块造的零件。**现在不用记住细节,只要知道"哦,原来一个完整的 agent 是由这些部分拼起来的"。** 后面 [六阶段路线图](04-六阶段路线图.md) 会带你一步步过。

**阶段一 · 让它能动手**
- `s01 智能体循环` —— 上面那个圈,一切的地基
- `s02 工具使用` —— 给它多种工具,加工具不改循环
- `s03 权限闸门` —— 危险操作先问你,划好边界
- `s04 生命周期钩子` —— 在关键节点挂自动动作(记日志、拦截)

**阶段二 · 做复杂任务**
- `s05 任务清单` —— 干大事前先列计划、边做边勾
- `s06 子智能体` —— 大任务拆给"分身"去干,主线保持清爽
- `s07 技能加载` —— 专业知识用到时再调出来
- `s08 上下文压缩` —— 聊太久记忆满了,自动腾地方

**阶段三 · 记住与恢复**
- `s09 记忆系统` —— 跨次对话记住该记的
- `s10 系统提示组装` —— 开场白按当前情况动态拼
- `s11 错误恢复` —— 出错了自动重试/换路子

**阶段四 · 让任务长期跑**
- `s12 任务系统` · `s13 后台任务` · `s14 定时调度` —— 落盘记进度、慢活丢后台、到点自己触发

**阶段五 · 多智能体协作**
- `s15 团队` · `s16 协议` · `s17 自治` · `s18 工作树隔离` —— 从单兵到一支队伍

**阶段六 · 接外部能力**
- `s19 MCP 插件` —— 把外部工具(比如你的星见桥)插进来
- `s20 综合体` —— 把全部机制收口成一个系统

> 你已经熟悉的两个真实项目,就是这 20 件的"生产级实物":**Kimi(TypeScript)** 和 **CodeWhale(Rust)**——它俩每个机制都造好了,后面我会**读它们的源码当参照**,你只要指一句"照它来"就行。

## 五、记住这一章,只要一句话

> **循环属于模型,机制属于你(我们)。**
> 每加一个零件,你只问:**"这是为了解决什么痛点?没有它会怎么翻车?"**
> 想清楚这个,你就指挥得动我、也验收得了成果。至于代码长什么样——那是我的事。
