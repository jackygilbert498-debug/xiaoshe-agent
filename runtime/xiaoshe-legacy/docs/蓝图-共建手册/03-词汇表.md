# 03 · 词汇表:大白话 + 生活类比

> 不用背。当成字典:听我说话、给我下指令时,遇到不懂的词回这里查一下。
> 每个词:**一句话 + 一个生活类比 + 它在我们 harness 里管什么。**

---

## 最核心的几个

**Agent(智能体)**
能自己"想一步、做一步、再想一步"地把活干完的 AI。
🪄 类比:一个能听你派活、自己跑腿、跑完回来汇报的助理。
👉 我们要造的就是它的"身体和环境"。

**Harness(载具 / 壳)**
包在大模型外面、让它能真正干活的那一整套代码。
🪄 类比:车手是模型,**harness 就是那辆车**(方向盘、油门、仪表盘)。
👉 这本手册从头到尾就在讲怎么造这辆车。

**Agency(自主能力)**
"会思考、会判断、会决定下一步"的那种聪明劲儿。
🪄 类比:车手的驾驶天赋——天生训练好的,你买不到。
👉 它来自大模型本身,**不是我们造的**。我们造的是让这份聪明能落地的环境。

**Agent Loop(智能体循环)**
"问模型→执行工具→把结果带回→再问"那个转不停的圈。
🪄 类比:助理的工作节奏——接指令、去做、回来汇报、接下一条。
👉 整个 harness 的心脏。[01 章](01-心智模型.md)那张图就是它。

## 关于"工具"和"对话"

**Tool(工具)**
agent 能采取的一个具体动作:读文件、写文件、跑命令、上网、调你的总台。
🪄 类比:助理的一项技能/一件道具。
👉 给 agent 加能力 = 给它加工具。

**Tool Use / Tool Result(工具调用 / 工具结果)**
模型说"我要用读文件这个工具" = tool use;代码真去读了、把内容递回去 = tool result。
🪄 类比:助理说"我去查下资料"(use),查完把资料放你桌上(result)。
👉 这俩必须**配对**、顺序不能乱——这是最容易出错的地方,所以必须测。

**System Prompt(系统提示 / 开场设定)**
每次对话最开头,悄悄告诉模型"你是谁、你能用哪些工具、规矩是什么"的一段话。
🪄 类比:给新来的助理的"岗位说明书 + 公司规章"。
👉 它写得好不好,直接决定 agent 听不听话、判断准不准。

**Context Window(上下文窗口)**
模型一次能"看在眼里"的内容上限(对话历史 + 资料,有个总量)。
🪄 类比:助理桌面的大小——桌子就那么大,堆满了就放不下新东西。
👉 聊太久会"桌面爆满",所以需要下面的"压缩"。

**Token(token)**
模型计量文字多少的单位(约等于"字/词的碎片"),上下文上限、花多少钱都按它算。
🪄 类比:出租车的"跳表"——你说的、它回的,都在跳表计费。
👉 你只要知道:**token 越省,越便宜越快**,所以压缩很重要。

## 让它扛住复杂、长期任务

**Compaction(上下文压缩)**
桌面快满时,把旧内容**总结/精简**腾出空间,别让它忘事或爆掉。
🪄 类比:助理把一摞旧资料浓缩成一页摘要,旧的归档。
👉 长任务能不能扛住,全靠它。

**Memory(记忆系统)**
跨次对话也能记住的东西(存成文件,不随对话清空)。
🪄 类比:助理的笔记本——今天关了电脑,明天还在。
👉 让 agent"认识你、记得你的偏好和项目"。

**Subagent(子智能体 / 分身)**
主 agent 派一个"分身"去单独干一段脏活,干完只把结论带回来。
🪄 类比:你让助理"找个实习生把这堆表格整理完,整理好给我结论就行"。
👉 大任务拆小、主线不被细节淹没。

**Permission(权限闸门)**
危险动作(删文件、花钱)执行前,先按规矩拦一下、或问你一句。
🪄 类比:助理动你的钱包前必须先问你。
👉 安全的命根子。你在星见上守的"绝不碰 8 个付费 API",就是它。

**Hook(钩子)**
在关键节点(用工具前/后、收到消息时)自动触发的小动作。
🪄 类比:门口的感应灯——有人经过(事件)就自动亮(动作)。
👉 用来挂日志、拦截、通知,不用改主循环。

## 让它长期跑、能恢复、能联外

**Background Task(后台任务)**
把慢活(装依赖、转码大视频)丢后台跑,主线不卡着等。
🪄 类比:洗衣机开着,你该干嘛干嘛,洗好了它叫你。

**Replay / 错误恢复**
出错或崩了,能从记录里"重放"回到之前的状态,接着干。
🪄 类比:游戏存档——挂了从最近的存档点读回来。

**Persistence(持久化 / 落盘)**
把状态写进硬盘文件,关机/重启也不丢。
🪄 类比:把进度存到硬盘,而不是只放在随时会断电的内存里。

**MCP(一种"工具插座"标准)**
一个通用标准,让 agent 能即插即用地接上外部工具(比如你的星见桥)。
🪄 类比:USB 接口——符合标准的设备插上就能用,不用为每个改线路。
👉 星见就是通过 MCP 把"总台视频工具"插给 Kimi 的。

---

## 关于"怎么保证不出错"

**Test(测试)**
一个自动检查"功能对不对"的小程序,我每造一块就配一个。
🪄 类比:质检流水线上的自动检测仪。
👉 **你这个不读代码的人,验收主要就靠看测试绿不绿。**

**Regression(回归测试)**
重跑全部老测试,确认"加新东西没把老功能弄坏"。
🪄 类比:改完一处,把全车再检一遍,确认别处没被碰坏。
👉 星见那 32 个测试,就是它的回归套件。

**Contract(契约)**
一份大白话说明书:这个模块该做什么、不该做什么、输入输出长啥样。
🪄 类比:岗位职责书 + 验收标准。
👉 让系统不越改越乱,也让我跨会话不失忆。
