# 模型就绪验证

“已验证”表示：当前 host 运行周期内，指定服务商和模型的显式探测成功，公开路由配置仍匹配，且结果未超过有效期。它不是仅凭模型出现在目录中得出的判断。

重启小蛇或重新加载此插件后，旧探测结果会保留为历史记录，但不再算当前“已验证”；请重新执行探测。刷新中、探测中或刷新失败时，也不会沿用旧的 verified 标记。

修订摘要不包含凭据值、任意请求头值或 URL 中的用户名、密码、查询串和片段。环境配置以每次 host 挂载生成的非秘密 epoch 隔离，避免把环境密钥当作版本摘要。运行期间在同一凭据引用下轮换密钥仍需重新显式探测；尚未接入凭据服务的非秘密变更修订。

局部回归（依赖须已安装）：`npm.cmd test --prefix packages/provider-readiness`。
